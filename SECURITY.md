# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The Deep Lens maintainers take security and data privacy seriously.

If you discover a security vulnerability within Deep Lens:

1. **Do not disclose the vulnerability publicly** in GitHub issues, discussion boards, or social media.
2. Email a detailed vulnerability report to **security@deeplens.ocean**.
3. Include:
   - Detailed steps to reproduce the issue.
   - Affected service, router, or package.
   - Potential impact on data integrity, API access, or credentials.
4. The maintainers will acknowledge receipt within 48 hours and provide an estimated timeline for remediation.
5. Once a security patch has been developed, tested, and released, public disclosure will follow with proper credit to the reporter.

## Responsible Environmental Intelligence Disclosures

Deep Lens processes environmental observation telemetry. Security reports concerning unauthenticated data alteration, unauthorized incident status modifications, or API credential leaks receive top priority.
