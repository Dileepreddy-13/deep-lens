# Project Governance

## Overview

Deep Lens is an open-source ocean intelligence project maintained by a community of software engineers, geospatial data specialists, physical oceanographers, and marine conservationists.

## Roles and Responsibilities

### Contributors
Anyone who submits issues, pull requests, documentation updates, dataset adapters, or scientific peer reviews.

### Reviewers
Domain specialists who evaluate pull requests for code quality, scientific validity, coordinate bounds, and license compliance.

### Maintainers
Active core developers with commit access responsible for:
- Repository integrity and release engineering.
- Enforcing the Code of Conduct.
- Reviewing pull requests and managing roadmap milestones.
- Ensuring zero credential leaks and verifying dataset licenses.

## Decision-Making Process

- **Technical Improvements:** Discussed publicly in GitHub Issues and Discussions. Consensus is reached through open peer review.
- **Scientific Methodology Changes:** Modifications to detection thresholds, Otsu segmentation formulas, or physical drift leeway require documented empirical rationale or peer-reviewed literature citations.
- **Licensing Compliance:** Only datasets with permissive open-access or clear attribution terms (e.g. CC-BY 4.0, Public Domain, Copernicus Open Access) may be integrated.
